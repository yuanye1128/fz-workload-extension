# FZ 工单工作量统计 Chrome 扩展

用于在 `https://kb.fzyun.net` 上，按月份统计本人相关的提测与可计入工作量的工单。

推荐在知识库 **「我的活动」** 页面使用。

## 两种统计

| 按钮 | 含义 |
|---|---|
| **提测工单数** | 粗略统计：活动中改为「待测试」的工单数 |
| **完成工作量** | 可计入工作量：按「已完成」当月结算（含「待测试 → 已完成」） |

### 完成工作量规则（摘要）

- 默认按当前登录用户统计。
- 计入「已完成」所在月份；更早改为「待测试」的贡献人，在完成当月计入。
- 收集活动候选时，会额外往前看 **1 个月** 的「待测试」记录，便于跨月结算。
- 活动流里勾选月已出现「已完成」时，可走短路径直接记当月，不再拉该工单详情；同一工单后续再出现也会跳过。
- 同一工单同一操作者同一月份去重，只计 1 条。

## 安装方式

1. 打开 Chrome，访问 `chrome://extensions/`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本仓库目录（含 `manifest.json` 的目录）。

修改代码后，在扩展管理页点击「重新加载」再试。

## 使用方式

1. 在浏览器中登录知识库。
2. 点击工具栏扩展图标：
   - **已在「我的活动」页**：直接打开页面右下角统计面板（不弹小窗）。
   - **不在活动页**：弹出小窗；点「打开统计面板」时，若能识别用户 ID，会自动跳转到「我的活动」并打开面板；识别不到则提示先手动进入活动页。
3. 在面板中勾选月份（可多选，支持年份切换）。
4. 按需点击 **提测工单数** 或 **完成工作量**。
5. 查看结果、月度柱状图；需要时可 **导出 HTML 报表**。统计过程中可点 **停止**。

## 实现说明

扩展不保存账号密码，也不请求外部服务。  
在 `kb.fzyun.net` 页面内运行，复用当前登录态，通过 `fetch(..., credentials: "include")` 拉取活动页与工单详情 HTML。

主要文件：

| 文件 | 作用 |
|---|---|
| `manifest.json` | Chrome 扩展声明 |
| `background.js` | Service Worker：活动页直开面板、按用户 ID 跳转「我的活动」 |
| `popup.html` / `popup.js` / `popup.css` | 非活动页时的工具栏弹窗 |
| `content.js` | 注入页面的统计与结算逻辑 |
| `content.css` | 右下角统计面板样式 |
| `test/cross-month-detailed.test.js` | 跨月结算 / 短路径相关纯逻辑测试 |

本地可运行：

```bash
node test/cross-month-detailed.test.js
```

## 调试建议

若结果不准，优先检查：

1. 是否在本人「我的活动」页，且已登录。
2. 活动/详情历史中是否能识别「待测试」「已完成」及日期。
3. 顶栏「登录为」用户链接是否为 `/users/数字ID`（用于自动跳转活动页）。

控制台日志前缀：

```text
[KB Workload]
```

## 已知限制

- 依赖知识库页面 HTML 结构；改版后可能需要调整解析逻辑。
- 历史若只有相对时间（如「3 天前」），无法准确归属月份。
- 未能识别用户 ID 时，不会使用 `user_id=me` 猜测跳转，需手动打开「我的活动」。
